プライバシーポリシー

「チャンネル管理（channel-manager）」（以下、この道具）が、Google のアカウントで許可された情報をどう扱うかを説明します。
最終更新：2026年10月17日

1. 使う許可

  • YouTube の読み取り（youtube.readonly）：自分のチャンネルの名前と動画の一覧を読むため
  • YouTube Analytics の読み取り（yt-analytics.readonly）：自分の動画の再生数・平均視聴率・流入元などの数字を読むため

どちらも読み取りだけです。動画の変更・削除・投稿・コメントなどは行いません。

2. 読む情報と使いみち

許可したチャンネルの動画の数字（再生数・総再生時間・平均視聴率・登録者の増加・流入元・関連動画の一覧）を読み、使う人がチャンネルの運営を考えるための一覧・グラフ・分析に使います。広告や、ほかの目的には使いません。

3. 保存する場所

読んだ情報と許可の鍵は、使う人のパソコンの中にだけ保存します。この道具の作者や、ほかのサーバーには送りません。

4. ほかに渡す情報

分析の文章を作るときに、動画の題名と数字を、使う人のパソコンにある Claude Code（Anthropic 社の AI）に渡します。それ以外の第三者には渡しません。売ることもありません。

5. Google のポリシーの順守

この道具が Google API から受け取った情報の使い方と、ほかのアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の決まりを含む）に従います。

6. 許可の取り消しと削除

許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。保存した情報は、使う人がパソコンの中の記録のファイル（data フォルダ）と許可のファイル（config フォルダ）を消すと、すべて消えます。
